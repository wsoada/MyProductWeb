SourceSure Logo Folder
======================

Place your replaceable logo files in this folder.

Recommended files:
- logo.png        -> main website logo (transparent background recommended)
- logo-white.png  -> optional white version for dark background use
- favicon.png     -> optional favicon source

Recommended size:
- Header logo height: about 40px visual height
- Source file: at least 400px wide, transparent PNG or SVG preferred

Currently referenced by pages:
- /index.html
- all generated category pages under /products/

If logo.png is missing, the website will automatically fall back to a text logo: SourceSure
